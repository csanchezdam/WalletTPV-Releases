# 🗺️ Hoja de Ruta

Plan estratégico con los próximos lanzamientos, características y objetivos de la aplicación.

---

## 🟢 En progreso
> Objetivos actuales y características en desarrollo activo.

### 🏪 Terminal Punto de Venta (TPV) / Sala
- **Saldo de cliente:** Opción para imprimir directamente en sala el saldo actual de cada cliente.
- **Asignación rápida:** Funcionalidad para asignar un cliente directamente desde la interfaz del TPV.

---

## 🟡 Próximamente
> Prioridades aprobadas para las siguientes etapas de desarrollo.

### 📱 Hardware y Acceso
- **Identificación inteligente:** Sistema para asignar clientes desde el TPV mediante escaneo de código QR o tecnología RFID.

### ⚙️ Backoffice y Mantenimiento
- **Exportación de logs:** Herramienta directa para descargar los registros del sistema desde el panel de administración.
- **Copias de seguridad:** Sistema para realizar backups completos de la configuración con un solo clic.

---

## 🔵 En consideración
> Propuestas futuras en proceso de análisis.

### ✨Nuevas características
- **Sistema de mailing:** Integración de comunicaciones y correos automatizados para los clientes.
- **Actualización automática:** Mecanismo para actualizar la aplicación de forma desatendida y automática.
